# Starblade - releases

Built files only (no source code).

**Windows :** telecharger [StarbladeLauncher-0.4.0-setup.exe](https://github.com/monkeykingstudio/starblade-releases/releases/download/launcher-v0.4.0/StarbladeLauncher-0.4.0-setup.exe), l'executer, puis cliquer INSTALLER.

**macOS :** telecharger [StarbladeLauncher-0.4.0-macos.dmg](https://github.com/monkeykingstudio/starblade-releases/releases/download/launcher-v0.4.0/StarbladeLauncher-0.4.0-macos.dmg), glisser Starblade Launcher dans Applications.
Au premier lancement, macOS le bloque (application non notarisee) : Reglages Systeme > Confidentialite
et securite > Ouvrir quand meme.
